Flight Chalker security check

This page tries the things a stranger could try, using only the public key, and tells you whether the database blocked them. Nothing real is changed: every test uses made-up IDs.

Step 1 — Before the lock-down (migration 07b)

Checks that the secure session header reaches the database. This must say PASS before you run migration 07b.

Step 2 — After the lock-down

Every line below should say PASS. A FAIL means that door is still open. (Edits and deletes of existing rows can’t be proven safe from a browser without touching real data, so those are checked by the server-side test suite instead.)
